3!
4! Packing and time averaging for the MG interface.
5!
6! Use is as follows:
7!
8! 1) Figure out which columns will do averaging (mgncol) and the number of
9! levels where the microphysics will run (nlev).
10!
11! 2) Create an MGPacker object and assign it as follows:
12!
13! packer = MGPacker(pcols, pver, mgcols, top_lev)
14!
15! Where [pcols, pver] is the shape of the ultimate input/output arrays
16! that are defined at level midpoints.
17!
18! 3) Create a post-processing array of type MGPostProc:
19!
20! post_proc = MGPostProc(packer)
21!
22! 4) Add pairs of pointers for packed and unpacked representations, already
23! associated with buffers of the correct dimensions:
24!
25! call post_proc%add_field(unpacked_pointer, packed_pointer, &
26! fillvalue, accum_mean)
27!
28! The third value is the default value used to "unpack" for points with
29! no "packed" part, and the fourth value is the method used to
30! accumulate values over time steps. These two arguments can be omitted,
31! in which case the default value will be 0 and the accumulation method
32! will take the mean.
33!
34! 5) Use the packed fields in MG, and for each MG iteration, do:
35!
36! call post_proc%accumulate()
37!
38! 6) Perform final accumulation and scatter values into the unpacked arrays:
39!
40! call post_proc%process_and_unpack()
41!
42! 7) Destroy the object when complete:
43!
44! call post_proc%finalize()
45!
46! Caveat: MGFieldPostProc will hit a divide-by-zero error if you try to
47! take the mean over 0 steps.
48!
49

51! builds.
