22
23 dp(t+3)-dp(t) = -3dt div(Udp_sum/3) - 3dt d(eta_dot_dpdn_sum/3) + 3dt D(dpdiss_sum/3)

25Where the floating lagrangian component:

28 dp_star(t+3) = dp(t+1) + 3dt d( eta_dot_dpdn_ave(t) )
29
30

32For consistency, if Q=1
33 dp1 = dp(t)- dtq div[ U1 dp(t)]
34 dp2 = dp1 - dtq div[ U2 dp1 ] + 2*dtq D( dpdiss_ave )
35 dp* = (dp(t) + dp2 )/2

39 U1 = Udp_ave / dp(t)

44 Qdp2 = Qdp1 - dtq div[ U2 Qdp1 ] + 2*dtq D( Q dpdiss_ave )
