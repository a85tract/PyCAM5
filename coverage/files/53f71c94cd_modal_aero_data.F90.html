261! nspec_amode(m) = number of chemical species in aerosol mode m
262! nspec_amode_ccm2(m) = . . . while in ccm2 code
263! nspec_amode_gchm(m) = . . . while in gchm code
264! nspec_amode_nontracer(m) = number of "non-tracer" chemical
265! species while in gchm code
266! lspectype_amode(l,m) = species type/i.d. for chemical species l
267! in aerosol mode m. (1=sulfate, others to be defined)
268! lmassptr_amode(l,m) = gchm r-array index for the mixing ratio
269! (moles-x/mole-air) for chemical species l in aerosol mode m
270! that is in clear air or interstitial air (but not in cloud water)
271! lmassptrcw_amode(l,m) = gchm r-array index for the mixing ratio
272! (moles-x/mole-air) for chemical species l in aerosol mode m
273! that is currently bound/dissolved in cloud water
274! lwaterptr_amode(m) = gchm r-array index for the mixing ratio
275! (moles-water/mole-air) for water associated with aerosol mode m
276! that is in clear air or interstitial air
277! lkohlercptr_amode(m) = gchm r-array index for the kohler "c" parameter
278! for aerosol mode m. This is defined on a per-dry-particle-mass basis:
279! c = r(i,j,k,lkohlercptr_amode) * [rhodry * (4*pi/3) * rdry^3]
280! numptr_amode(m) = gchm r-array index for the number mixing ratio
281! (particles/mole-air) for aerosol mode m that is in clear air or
282! interstitial are (but not in cloud water). If zero or negative,
283! then number is not being simulated.
284! ( numptr_amode_gchm(m) = same thing but for within gchm
285! numptr_amode_ccm2(m) = same thing but for within ccm2
286! These are temporary, to allow testing number in gchm before ccm2 )
287! numptrcw_amode(m) = gchm r-array index for the number mixing ratio
288! (particles/mole-air) for aerosol mode m
289! that is currently bound/dissolved in cloud water
290! lsfcptr_amode(m) = gchm r-array index for the surface area mixing ratio
291! (cm^2/mole-air) for aerosol mode m that is in clear air or
292! interstitial are (but not in cloud water). If zero or negative,
293! then surface area is not being simulated.
294! lsfcptrcw_amode(m) = gchm r-array index for the surface area mixing ratio
295! (cm^2/mole-air) for aerosol mode m that is currently
296! bound/dissolved in cloud water.
297! lsigptr_amode(m) = gchm r-array index for sigmag for aerosol mode m
298! that is in clear air or interstitial are (but not in cloud water).
299! If zero or negative, then the constant sigmag_amode(m) is used.
300! lsigptrcw_amode(m) = gchm r-array index for sigmag for aerosol mode m
301! that is currently bound/dissolved in cloud water.
302! If zero or negative, then the constant sigmag_amode(m) is used.
303! lsigptrac_amode(m) = gchm r-array index for sigmag for aerosol mode m
304! for combined clear-air/interstial plus bound/dissolved in cloud water.
305! If zero or negative, then the constant sigmag_amode(m) is used.
306!
307! dgnum_amode(m) = geometric dry mean diameter (m) of the number

309! (Only used when numptr_amode(m) is zero or negative.)

311! geometric dry mean diameter (m) of the number distribution
312! (Used when mprognum_amode>0, to limit dgnum to reasonable values)
313! sigmag_amode(m) = geometric standard deviation for aerosol mode m
314! sigmaglo_amode(m), sigmaghi_amode(m) = lower and upper limits on the
315! geometric standard deviation of the number distribution
316! (Used when mprogsfc_amode>0, to limit sigmag to reasonable values)
317! alnsg_amode(m) = alog( sigmag_amode(m) )

320! voltonumblo_amode(m), voltonumbhi_amode(m) = ratio of number to volume

324! alnv2n_amode(m), alnv2nlo_amode(m), alnv2nhi_amode(m) -
